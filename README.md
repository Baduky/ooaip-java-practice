# Практические работы по ООАиП (Java)

Побокина Валерия Владиславовна, 38.03.05 «Бизнес-информатика».

Все задания ПР1–ПР4.1 находятся в `src/Main.java`.

| Класс | Практическая работа |
| --- | --- |
| `Pr1` | ПР1 ч.1 — синтаксис, циклы, массивы, методы |
| `Pr1Dop` | ПР1 доп. — классы A, Rectangle, Stock |
| `Pr2` | ПР2 — Author |
| `Pr3` | ПР3 — абстрактный Shape, интерфейс Movable |
| `Pr4` | ПР4 — перечисления (enum) |
| `Pr41` | ПР4.1 — наследование и абстрактные классы |

## Запуск

Открыть папку в IntelliJ IDEA и запустить `Main.main()`, либо:

```
javac -encoding UTF-8 -d out src/Main.java
java -cp out Main
```

После запуска появится меню: номер пункта запускает задание, `99` — все неинтерактивные задания подряд.
